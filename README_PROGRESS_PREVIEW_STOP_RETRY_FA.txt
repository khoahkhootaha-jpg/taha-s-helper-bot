تغییرات این نسخه:
- درصد پیشرفت تقریبی هنگام ساخت کد/سایت (تا زمان پاسخ سرور تا ۹۴٪ می‌رود و بعد از موفقیت ۱۰۰٪ می‌شود). این درصد واقعی سمت API نیست، چون API فعلی درصد واقعی ارائه نمی‌کند.
- دکمه ارسال هنگام انتظار به دکمه مربعی توقف تبدیل می‌شود؛ با زدن آن درخواست مرورگر لغو می‌شود.
- دکمه «تلاش مجدد» برای پیام‌های خطا/توقف.
- پیش‌نمایش HTML موجود حفظ شده و پس از ساخت موفق قابل بازکردن است.
- طراحی اصلی حفظ شده است.
