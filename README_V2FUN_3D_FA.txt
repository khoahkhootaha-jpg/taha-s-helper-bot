افزوده‌شده: ساخت مدل سه‌بعدی با V2Fun

۱) در داشبورد Render وارد بخش Environment شو.
۲) متغیر زیر را اضافه کن و مقدار API Key خودت را آنجا وارد کن:
   V2FUN_API_KEY = کلید خصوصی V2Fun
۳) کلید را داخل چت یا کد عمومی نگذار.
۴) Deploy را دوباره اجرا کن.
۵) در برنامه از منوی ⋮ گزینه «ساخت مدل سه‌بعدی» را انتخاب کن؛ متن مدل، بافت و فرمت GLB/OBJ/FBX را تنظیم کن.

نکته‌ها:
- تولید مدل و تبدیل فرمت ممکن است چند دقیقه طول بکشد و به اعتبار API نیاز دارد.
- مدل پایه معمولاً ۲۰ اعتبار، بافت استاندارد +۲۰ و تبدیل فرمت +۵ اعتبار مصرف می‌کند؛ هزینه نهایی را در مستندات V2Fun بررسی کن.
- قابلیت خودکار rigging به این نسخه اضافه نشده؛ V2Fun در این بخش فقط ساخت مدل و تبدیل فرمت را انجام می‌دهد.
- لینک دانلود به فایل داخل برنامه تبدیل می‌شود تا کاربر بتواند مدل را دانلود کند.
