Taha's Helper Bot — V2Fun 3D Fix

این نسخه برای رفع اشکال دکمه ساخت مدل سه‌بعدی و نمایش خطای واقعی V2Fun آماده شده است.

نصب روی Render:
1) ZIP را از حالت فشرده خارج کن و فایل‌های داخل پوشه taha52 را در مخزن پروژه جایگزین کن.
2) در Render > Environment متغیر V2FUN_API_KEY را با کلید API خودت تنظیم کن. کلید را در چت یا کد قرار نده.
3) Deploy را انجام بده و بعد از باز شدن سایت یک بار صفحه را کامل Refresh کن.
4) منوی سایت > «ساخت مدل سه‌بعدی» > یک prompt کوتاه مثل a wooden chair وارد کن و فرمت GLB را انتخاب کن.

تغییرات:
- بازنویسی مدیریت خطای رابط کاربری؛ خطای HTTP و پیام سرور دیگر بی‌صدا گم نمی‌شود.
- پیام خطا در خود پنل مدل سه‌بعدی نمایش داده می‌شود.
- لاگ‌های امن‌تر برای تشخیص پاسخ و وضعیت V2Fun در Render Logs اضافه شده‌اند؛ کلید API لاگ نمی‌شود.
- بررسی وضعیت و خطاهای تو در تو در پاسخ JSON مقاوم‌تر شده است.

نکته: این نسخه به کلید فعال V2Fun API و اعتبار کافی نیاز دارد. اگر API خود V2Fun وضعیت FAILED برگرداند، برنامه اکنون جزئیات بیشتری نشان می‌دهد؛ رفع مشکل سمت حساب/سرویس بدون پاسخ API امکان‌پذیر نیست.
