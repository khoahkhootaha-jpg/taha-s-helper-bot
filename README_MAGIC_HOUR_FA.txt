نسخهٔ به‌روزشدهٔ Taha's Helper Bot — Magic Hour

- برای Render، مقدار MAGIC_HOUR_API_KEY را در Environment قرار دهید.
- کلید را در کد یا مرورگر قرار ندهید.
- ساخت ویدیو از API رسمی Magic Hour انجام می‌شود؛ درخواست‌ها از اعتبار حساب Magic Hour مصرف می‌کنند.
- طراحی صفحه حفظ شده و سرویس ویدیو از Vadoo به Magic Hour تغییر کرده است.
- این نسخه در این محیط امکان آزمایش واقعی API با کلید حساب شما را ندارد. اگر پاسخ API متفاوت باشد، خطای آن در Render Logs نمایش داده می‌شود.
