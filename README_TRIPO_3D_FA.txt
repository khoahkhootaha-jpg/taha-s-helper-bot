معراج / Taha's Helper Bot — افزونه ساخت مدل سه‌بعدی Tripo AI

راه‌اندازی در Render:
1) در Dashboard سرویس → Environment متغیر TRIPO_API_KEY را اضافه کن و API key سرویس Tripo را در Value قرار بده. کلید را در کد یا چت قرار نده.
2) بعد از ذخیره، سرویس را redeploy کن.
3) در صفحه ربات روی دکمه 🧊 بزن. می‌توانی متن بنویسی، عکس PNG/JPG/WebP بدهی، فرمت خروجی انتخاب کنی و برای مدل‌های مناسب Rigging را فعال کنی.

قابلیت‌ها:
- ساخت 3D از متن یا عکس
- وضعیت واقعی task از Tripo، timeout پانزده‌دقیقه‌ای و تلاش مجدد برای درخواست متنی
- Rig check رایگان قبل از rigging و خروجی GLB/FBX برای مدل rigged
- تبدیل خروجی به GLB, FBX, OBJ, STL, GLTF, USDZ, 3MF طبق محدودیت‌های سرویس
- فایل مدل پس از موفقیت در سرور ذخیره می‌شود تا لینک کوتاه‌عمر Tripo بلافاصله دانلود شود.

توجه: مصرف اعتبار Tripo ممکن است برای تولید، rigging و تبدیل اعمال شود. OBJ/STL/3MF برای مدل rigged/انیمیشن مناسب نیستند و ممکن است انیمیشن یا تکسچر را حفظ نکنند. ساخت واقعی نیاز به کلید معتبر و اعتبار حساب Tripo دارد؛ در این محیط با کلید شخصی شما تست زنده نشده است.

مستندات رسمی: https://developers.tripo3d.com/en/docs/introduction
